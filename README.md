# Desky

A cross-platform project-context launcher for fast re-entry into a working
directory and its editor, terminal, applications, and saved web resources.

Current state: product and terminal-interface design documents. Application
code, a selected stack, and executable verification have not been added. The
first autonomy-pilot task is a concrete architecture/specification and incremental
implementation plan, as requested in `plan.md`.
